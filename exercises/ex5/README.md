# Exercise 5 - Freestyle

> **What you will do:** take off the rails. You have finished the guided tabs, so the **Freestyle** tab is unlocked. Ask your own questions, as any of a set of business roles on SAP S/4HANA, and tell us how the agent did.

## Step 1 - Enter the passcode

Finishing every guided tab reveals a passcode (shown in the progress strip once all tabs are complete). Open the **Freestyle** tab and enter it to unlock the playground.

> [!TIP]
> If the tab is still locked, go back and finish any tab whose strip is not at full count. Every step has to be done.

## Step 2 - Ask your own questions

Pick any role from the selector. The roles span sales, finance, purchasing, production, maintenance, master data, and service, and each one sends its own authorization grants, so the agent is scoped to what that role can reach. The starter questions under the box change with the role you pick. They are a jumping-off point; this is a free text box, so type whatever you like.

> [!TIP]
> This is the place to point the agent at your own work. Try a question you would actually ask on the job, and see how it handles your real use case.

Some things worth trying:

- The same question as two different roles, to see the scope change.
- A multi-step question that needs a join (an order and its delivery, a customer and their totals).
- A question you would actually ask in your own work.
- Something you expect it to get wrong, to see how it fails (it should tell you when it cannot answer).

You get the full agent trace on every answer, the same one you read in the Simulator: resolve, generate, execute, verify. If an answer is not what you expected, rephrase the question or add more specific detail and ask again.

## Step 3 - Tell us how it did

Under each answer, tell us whether it was useful and whether it was correct, and leave a comment if you have one. At the bottom of the tab there is a short closing rating for the agent and for the workshop itself. It is all anonymous, and the honest reactions (including the misses) are the ones we learn the most from.

That wraps up the hands-on exercises. Thanks for attending AS263. For questions and feedback after the session, use the [Issues](../../issues) tab.
