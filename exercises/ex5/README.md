# Exercise 5 - Freestyle

You have finished the guided tabs, so the **Freestyle** tab is unlocked. This is the one place with no rails: a free text box, a wide set of roles across two SAP systems, and your own questions.

## Step 1 - Enter the passcode

Finishing every guided tab reveals a passcode (shown in the progress strip once all tabs are complete). Open the **Freestyle** tab and enter it to unlock the playground.

> If the tab is still locked, go back and finish any tab whose strip is not at full count. Every step has to be done.

## Step 2 - Ask your own questions

Pick any role from the selector. There are far more here than the guided tabs showed: roles across more than one SAP system, spanning sales, finance, purchasing, maintenance, production, master data, and more. Each role sends its own authorization grants, so the agent is scoped to what that role can reach.

Type any question you like and run it. Some things worth trying:

- The same question as two different roles, to see the scope change.
- A multi-step question that needs a join (an order and its delivery, a customer and their totals).
- A question you would actually ask in your own work.
- Something you expect it to get wrong, to see how it fails (it should tell you when it cannot answer).

You get the full agent trace on every answer, the same one you read in the Simulator: resolve, generate, execute, verify.

## Step 3 - Tell us how it did

Rate each answer with the thumbs control under it, and leave a comment. This is real feedback that goes to the team; the honest reactions (including the misses) are the useful ones.

That wraps up the hands-on exercises. Thanks for attending AS263. For questions and feedback after the session, use the [Issues](../../issues) tab.
